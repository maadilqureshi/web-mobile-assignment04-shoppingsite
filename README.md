# IDEAL SHOP — E-commerce Shopping Website UI

A static e-commerce website interface created as a web and mobile development assignment. The project demonstrates common storefront UI patterns using HTML, CSS, Bootstrap, and Font Awesome.

**Live demo:** https://maadilqureshi.github.io/web-mobile-assignment04-shoppingsite/

## Overview

The repository contains a shopping-style homepage with a navigation bar, product-related content, image carousel, and supporting informational pages. This is a front-end demonstration, **not** a complete online store or a production checkout system.

## Project structure

```text
.
├── index.html            # Storefront homepage
├── Products/             # Product-related assets/content
├── pages/                # About, contact, services, and thank-you pages
├── slider/               # Carousel images
├── stylesheet/style.css  # Custom styles
└── web-logo/             # Branding assets
```

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Explore the navigation and supporting pages.

No build tooling is required for the current static site. Some styling and icons are loaded from third-party CDNs, so an internet connection may be needed for the intended appearance.

## Technologies

- HTML5
- CSS3
- Bootstrap 4.5 (CDN)
- Font Awesome 4.7 (CDN)
- GitHub Pages

## Current limitations

- This is a learning/portfolio project and does not provide real inventory, payment processing, or order management.
- Some links navigate to external shopping websites.
- The original project may need additional mobile, accessibility, link, and dependency review before real-world use.
